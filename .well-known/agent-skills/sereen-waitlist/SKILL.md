# Sereen — Join the Waitlist

## Description
Guides AI agents on how to help users join Sereen's pilot program waitlist.

## Waitlist Overview
Sereen is currently accepting applications for its pilot program. Interested users can register via the waitlist form on the website.

## How to Join (for agents helping users)
1. Direct the user to https://sereen.pt
2. The waitlist form is accessible via the "Lista de espera" button in the navigation bar, or by scrolling to the bottom of the page.
3. Required fields:
   - **Nome** — full name
   - **Email** — valid email address
   - **Telefone** — phone number
4. After submitting, the Sereen team will reach out to schedule the initial psychiatric evaluation.

## WebMCP
If the page supports WebMCP, agents can call the `join-waitlist` tool to scroll to and focus the form automatically.

## Notes
- The waitlist is free to join
- No commitment required at sign-up
- The team contacts each applicant individually
