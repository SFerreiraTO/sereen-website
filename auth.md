# auth.md — Sereen

Sereen (sereen.pt) é um serviço público de informação sobre tratamento de depressão com tDCS em casa.

## Acesso público

Este site é totalmente público. Não é necessária autenticação para aceder ao conteúdo.

## Registo na lista de espera

Agentes que pretendam ajudar utilizadores a aderir ao programa piloto podem fazê-lo enviando o utilizador para o formulário disponível em https://sereen.pt/ (secção "Lista de espera").

Campos necessários:
- nome (texto)
- email (email válido)
- telefone (número de telefone)

## Sem API protegida

Este site não disponibiliza APIs protegidas. Não existem credenciais, tokens de acesso ou endpoints OAuth associados a este domínio.

## Contacto

Para questões relacionadas com agentes ou integrações: https://sereen.pt
